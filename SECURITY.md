# Security policy

Do not open a public issue for a suspected credential, private URL, confidential implementation detail or sensitive data exposure.

Email [hello@getnameframe.com](mailto:hello@getnameframe.com) with the subject `NameFrame public repository security report`. Include the affected URL or file, the impact, and enough reproduction detail to verify the report without including unrelated private data.

This repository contains public content and a static site, not the NameFrame software. Product security reports should use the private contact route published on the official NameFrame site.
