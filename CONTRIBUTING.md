# Contributing

This is a public evidence and sample-data repository for proprietary NameFrame software. It is not an open-source software project and does not accept plugin or pipeline contributions.

Useful contributions include:

- broken-link reports;
- corrections to public dataset metadata;
- archive-hash mismatches;
- documentation clarity fixes;
- accessibility issues;
- reproducible problems in the published sample files.

Before opening a pull request, identify the dataset name and version, the exact file or URL, the expected result, the observed result and the public evidence supporting the correction. Changes to dataset facts must update the dataset card and registry together.

Do not submit confidential customer data, private API details, proprietary implementation material, third-party assets without redistribution rights or requests for the NameFrame source code.

By contributing, you confirm you have the right to submit the material and agree that the repository owner may publish it under the repository's applicable terms.
